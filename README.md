# AI 卡片炼金术 · AI Card Alchemy

> 丸子的无限进步

最近半年（2026 年 3—9 月）AI 世界里值得留下来的那一瞬，做成一张张小卡片，再配一套图像处理风格库。

**先挑卡片，再挑风格，然后复制一条能直接用的指令。**

## 怎么用

**最省事**：双击 `index.html`。数据是内联的，离线、不用起服务。

**想要扩充能力**：双击 `打开卡片风格库.bat`，或者

```bash
python scripts/studio_server.py      # http://127.0.0.1:8796
```

起服务后可以做这些事：

| 接口 | 作用 |
|---|---|
| `GET /api/data` | 拿全部卡片与风格 |
| `POST /api/card` | 新增一张卡片，自动写回 JSON 并重建页面 |
| `POST /api/style` | 新增一种风格 |
| `GET /api/export` | 导出 Markdown |

新增卡片示例：

```bash
curl -X POST http://127.0.0.1:8796/api/card -H "Content-Type: application/json" ^
  -d "{\"type\":\"语录\",\"title\":\"标题\",\"core\":\"一句话\",\"body\":\"正文\",\"source\":\"来源\",\"date\":\"2026-09\",\"tags\":[\"a\"],\"fit\":[\"zen-line\"]}"
```

手动改了 `data/alchemy.json` 之后，跑一次重建：

```bash
python scripts/build.py
```

## 两条底线

1. **事实**：每张卡片必须有可核查来源，新增时不凭印象编。
2. **人脸**：真实人物故事（蔡磊、王宁等）不生成可识别肖像，用背影、手部、剪影或物件代替。

输出统一带「丸子的无限进步」水印。
